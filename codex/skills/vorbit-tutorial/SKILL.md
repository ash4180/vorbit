# Vorbit Tutorial

Before writing:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/tutorial.md`.
3. Load the applicable durable Vorbit rules for the current project and Codex agent scope.
4. Then follow the tutorial workflow: find the doc pattern, read the feature, capture screenshots and a GIF when possible, draft the doc, get approval, save it, and offer Notion and Linear sharing.
