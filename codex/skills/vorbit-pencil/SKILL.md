# Vorbit Pencil

Before working in Pencil:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/pencil.md`.
3. Load the applicable durable Vorbit rules for the current project and Codex agent scope.
4. Then follow the Pencil workflow: verify Pencil, scan the codebase, extract tokens, build the Pencil component library, write project rules.
