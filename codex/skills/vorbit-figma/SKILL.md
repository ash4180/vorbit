# Vorbit Figma

Before working in Figma:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/figma.md`.
3. Load the applicable durable Vorbit rules for the current project and Codex agent scope.
4. Then follow the Figma workflow: inspect code and Figma, map the linked design system, plan pages from the journey, confirm each phase with the user, and create design-system-backed Figma screens or libraries.
