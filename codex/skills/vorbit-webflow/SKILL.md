# Vorbit Webflow

Before building in Webflow:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/webflow.md`.
3. Load the applicable durable Vorbit rules for the current project and Codex agent scope.
4. Then follow the webflow workflow: gather inputs, get design context, plan structure, build with MCP tools, confirm and document.
