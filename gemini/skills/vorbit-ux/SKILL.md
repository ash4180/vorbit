# Vorbit UX Clarification

Before clarifying UX:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/ux.md`.
3. Load the applicable durable Vorbit rules for the current project and Gemini agent scope.
4. Then follow the UX workflow: question by category, cross-check edge cases, output structured acceptance criteria using user's verbatim answers.
