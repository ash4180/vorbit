# Vorbit UI Patterns

Before building UI:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/ui-patterns.md`.
3. Load the applicable durable Vorbit rules for the current project and Gemini agent scope.
4. Then follow the UI patterns constraints: Tailwind, accessible primitives, animation limits, z-index scale.
