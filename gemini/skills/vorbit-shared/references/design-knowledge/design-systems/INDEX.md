# Design Systems Index

58 design system presets extracted from real websites. Source: [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT License).

## How to use

**Read on demand. Never load every file at once.** When the user says "make it look like X", read that one brand file.

Each file has 9 standard sections:

1. Visual Theme & Atmosphere: design philosophy and mood
2. Color Palette & Roles: full color system
3. Typography Rules: font hierarchy table
4. Component Stylings: buttons, cards, inputs, navigation
5. Layout Principles: spacing, grid, container widths
6. Depth & Elevation: shadow system
7. Do's and Don'ts: design guardrails
8. Responsive Behavior: breakpoints
9. Agent Prompt Guide: quick reference and component examples

Note: the Anthropic Claude preset lives in `claude-ai.md`. It was renamed from `claude.md` so Claude Code does not auto-load it as project instructions.
