# Vorbit Review Workflow

Use for code review or pre-PR review.

1. Load Vorbit durable rules first.
2. Prioritize findings over summaries: correctness, regressions, missing tests, and risky assumptions.
3. Reference concrete files and lines when possible.
4. Distinguish repo policy issues from Gemini-local mistakes learned in previous reviews.
5. If there are no findings, say so explicitly and note any residual risk or untested areas.
