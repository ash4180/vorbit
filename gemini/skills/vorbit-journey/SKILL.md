# Vorbit Journey

Before creating flows:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/journey.md`.
3. Load the applicable durable Vorbit rules for the current project and Gemini agent scope.
4. Then follow the journey workflow: gather context, confirm flow details, create Mermaid diagram in FigJam.
