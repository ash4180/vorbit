# Vorbit React Best Practices

Before writing React code:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/react-best-practices.md`.
3. Load the applicable durable Vorbit rules for the current project and Gemini agent scope.
4. Then apply priority-ordered guidelines: eliminate waterfalls, reduce bundle size, server-side performance, client data fetching, re-render optimization.
