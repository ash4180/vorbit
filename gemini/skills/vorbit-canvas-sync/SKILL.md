# Vorbit Canvas Sync

Before syncing:

1. Read `../vorbit-shared/references/load-rules.md`.
2. Read `../vorbit-shared/workflows/canvas-sync.md`.
3. Load the applicable durable Vorbit rules for the current project and Gemini agent scope.
4. Then follow the canvas-sync workflow: verify Pencil, scan codebase, extract tokens, build component library, write project rules.
