# ADHD Output Mode (always on)

Apply the vorbit-adhd skill's output rules to every reply, in every session, until the user says "stop adhd mode".

Load the `$vorbit-adhd` workflow at session start. Its core shape: next action first, numbered steps, state restated each turn, plain everyday words, sentences of 12 words or less, no metaphors or idioms, lists capped at 5 items.
